# 예겜 탐색·선택 UI 원칙

2026-10-10 기준. 벤치마킹은 타사 브랜드·거래 모델의 복제가 아니라, 질문 발견과 선택 이해를 개선하는 데 사용한다.

## 근거 범위

- Kalshi 홈, crypto 카테고리, BTC 상세를 로그인·거래 없이 실제 확인했다. 지속 검색, 주제/기간 필터, 이름이 붙은 선택지, 판정 출처, 구분된 타임라인을 관찰했다. 성과나 전환율 개선은 측정하지 않았다.
  - https://kalshi.com/
  - https://kalshi.com/category/crypto
  - https://kalshi.com/markets/kxbtc50vs100/will-btc-fall-below-50k-before-hitting-100k/kxbtc50vs100-btc-26dec31
- Polymarket 본사이트는 국내 HTTP 451 법적 접근 제한으로 현행 화면을 관찰하지 못했다. 제한을 우회하지 않았다.
- Polymarket 공식 Discover Markets 문서는 하나의 이벤트가 관련 질문들을 묶는 구조를 설명한다. 이 문서상 데이터 모델을 주제 묶음 설계에 참고할 수 있지만, 현행 홈페이지 UI를 관찰했다고 표현하면 안 된다.
  - https://docs.polymarket.com/market-data/discover-markets

## 지속 적용할 기준

1. 사용자가 첫 화면에서 **궁금한 질문**과 **선택의 의미**를 발견해야 한다. 보조 분석·안내가 실제 질문 카드를 아래로 밀지 않는다.
2. 검색과 주제 탐색을 쉽게 한다. 필터 개수, 참여량, 인기도는 실제 게시 데이터에만 근거한다. 미지원 분야를 이미 제공하는 것처럼 표현하지 않는다.
3. 질문은 일상 한국어로, 선택지는 완전한 조건으로 표시한다. `gt` 규칙의 YES는 초과, NO는 이하이며 동률은 NO다. UI가 저장된 판정 규칙을 바꾸거나 추측하지 않는다.
4. 참여 마감과 공식 관측/판정 기준 시각을 분리하고 KST를 명시한다. 마감 임박 정렬과 카운트다운은 `betting_end_date`를 사용한다. 마감 후에는 참여 행동을 제공하지 않는다.
5. 0참여 초기 50%를 예측 확률로 강조하지 않는다. 실제 참여가 있어도 저장된 초기 `yes_price`를 시장 의견처럼 제시하지 않는다. 제공되는 실제 인원·GAM 합계만 표시한다.
6. 질문의 맥락과 관련 분석, 판정 규칙 및 공식 출처는 구분한다. 허가된 실제 이미지나 데이터로만 보완한다. 가짜 차트·참여자·인기·거래량·댓글·추천·조회수를 만들지 않는다.
7. GAM은 환전·현금화 불가 자산이다. 투자 수익·현금 베팅·타사 배당 배수 표현을 모방하지 않는다.
8. 국내 뉴스·스포츠·영화·정책 주제를 우선 검토하되, KBO/KOBIS 등의 이용 허가·공식 API·수집기·자동 판정 규칙이 검증되기 전에는 게시하거나 제공 가능하다고 표시하지 않는다.

## 변경 검증 기준

- 원문, 제목, `resolution_params`, 모든 날짜, 정산 상태와 GAM 데이터는 보존한다. 이번 개선은 표시와 탐색만 변경한다.
- 규칙 없음·미지원 규칙·모호한 날짜는 조건을 지어내지 않고 참여 동작을 제공하지 않는다.
- 모바일/데스크톱, 검색/필터, 마감 직전·정각·이후, 초기값/실제 참여, 링크/키보드 접근을 확인한다.
- 배포 전 회귀 테스트, 배포 후 실제 공개 화면을 확인한다. 미리보기 화면을 운영 반영 증거로 사용하지 않는다.
- 향후 개선도 이 기준으로 타사 구조를 비교한다. 반복 자동 배포나 새 벤치마크 일정은 별도 승인 없이 추가하지 않는다.
